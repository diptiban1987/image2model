# ImageTo3D Pro Windows Installer

Professional Windows installer for ImageTo3D Pro v2.1.0

## Features

- Custom branding with logo
- Sample images included
- Documentation included
- Auto-upgrade from v2.0.0
- Desktop shortcut option
- Launch checkbox on finish

## Quick Build

```batch
build_all.bat
```

## Files Created

- Application: dist/ImageTo3DPro.exe
- Installer: installer/output/ImageTo3DPro_Setup_v2.1.0.exe

## Requirements

- Inno Setup 6
- Windows 7/8/10/11

## Installation Location

C:\Program Files\ImageTo3D Pro
